# Requirements-only brainstorm

## Requirements

- R1: Settle only the existing unique audit-blocked authentication failure that occurred before
  Modal issued an app, function-call, image, or submitted identity.
- R2: Accept only exact authoritative workspace billing bytes that prove USD 0 for a complete,
  unfiltered hourly interval covering the latest durable boundary plus the full 2,700-second action
  window and the existing completeness delay.
- R3: Bind the evidence to the authenticated workspace scope, billing method and authority,
  reservation, original execution scope, exact query interval, exact bytes, size, and SHA-256.
- R4: Preserve the consumed original U8 slot and semantic execution history. Never invent an ID,
  release unknown work, or convert the original action into an unused attempt.
- R5: Atomically settle the old reservation/run at USD 0 and create exactly one separately authorized
  replacement entitlement. Any mismatch, nonzero cost, incomplete interval, race, or ambiguity leaves
  the row audit-blocked and creates no entitlement.
- R6: The replacement may reserve at most USD 4.00 only after fresh WSL authentication, lineage,
  privacy, transport, memory, timing, clean-tree, resource, and budget gates pass.
- R7: Consume the replacement entitlement atomically at the final provider boundary. Any attempted,
  submitted, failed, timed-out, or ambiguous replacement consumes it permanently; no second replacement.
- R8: Keep workspace, profile, report, reservation, scope, and target details in ignored local artifacts.
  Public tracked code and documentation remain target-neutral.
- R9: Preserve one A100-80GB, one container/spawn, 2,700 seconds, zero retries/fallback, USD 4.00
  incremental cap, USD 4.00270969 cumulative lifetime cap, and every existing privacy restriction.
- R10: Keep configured 262,144-token context distinct from empirically proven-useful context.

## Out of scope

- Generic workspace-billing settlement, resetting the original slot, another replacement, U9 numeric
  approval, candidate conversion, training, promotion, persistent provider resources, or scheduling.
